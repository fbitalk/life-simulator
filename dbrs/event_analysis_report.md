## 九、迁移到人生模拟器的关键问题

### 1. 属性映射

dbrs 有 21 个显性属性 + 77 个隐性属性，而人生模拟器只有 8 个属性。需要：
- 将 dbrs 的扩展属性映射为**标签**（如「武力值高」「虔诚」等）
- 将隐性属性全部转换为**标签**（如 `=HIDDEN=龙珠收集进度` -> `龙珠收集进度` 标签）

### 2. 年龄系统差异

- dbrs 使用 `age_min`/`age_max`，上限 65535 表示无限制
- 人生模拟器使用 `age_range: [min, max]`
- dbrs 有「超人」年龄组(111+)，游戏可延续数百岁（修仙/龙珠线）
- 迁移方案：长寿命事件线需要放宽年龄上限

### 3. 事件链机制差异

- dbrs **没有显式的** `continue_event` 字段
- 事件链通过**标签驱动**隐式实现：事件A添加标签X → 标签X触发事件B
- 人生模拟器支持标签链 + `continue_event` 显式链，更灵活

### 4. 选项结果的条件分支

- dbrs 没有 `conditional_results`，所有分支通过**多个选项**实现
- 每个选项可设置不同的 `add_tags`，由后续事件通过 `required_tags` 自然分流

### 5. 时间流逝

- dbrs 通过 `pass_time` 字段控制每次选择推进的年数 (1-4年)
- 人生模拟器默认每年+1，需考虑是否支持跳跃多年
